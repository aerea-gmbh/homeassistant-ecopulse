# EcoPulse for Home Assistant

Custom integration (installable via HACS) that brings the live data of an EcoPulse EdgeGateway into Home Assistant,
local-first: it talks to the gateway's local HA API on your LAN, no cloud round-trip and no MQTT broker needed.

Status: in development (EcoPulse epic #610). Mirrored to GitHub for HACS.
